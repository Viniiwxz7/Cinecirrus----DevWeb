Como instalar e usar

A forma mais rápida de começar é via CDN no <head> do seu HTML:

<!-- Importando o framework via CDN -->
<link rel="stylesheet"
  href="https://unpkg.com/cirrus-ui/dist/cirrus.min.css">

<!-- Exemplo de uso de Card -->
<div class="card">
  <div class="card__container">
    <h2 class="card__title">Título do Card</h2>
  </div>
</div>
