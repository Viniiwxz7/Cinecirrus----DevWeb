# Direção visual — CineCirrus

O CineCirrus é uma interface didática de catálogo de cinema. A camada visual usa Cirrus CSS; a aplicação é renderizada no servidor com Express e Handlebars, e os registros são armazenados pelo Sequelize em SQLite.

A paleta usa azul-noite, ciano e âmbar para lembrar uma sala de cinema sem complicar a implementação. Cards apresentam as entidades, tabelas exibem listas, formulários mostram o cadastro e os exemplos de accordion, tabs e modal apoiam a apresentação.
